# Parallax Landscapes
Scrolling experience inspired by Covr theme on WordPress, recreated with landscape imagery from Unsplash.

## Tech Stack
- React
- Vite
- CSS

## Features
- Layered parallax scrolling
- Full-screen landscape sections
- Smooth scroll-based transitions
- Responsive layout

## Inspiration
This project was inspired by the [Covr theme](https://wordpress.com/theme/covr).

## Installation
```sh
npm install
npm run dev
```
